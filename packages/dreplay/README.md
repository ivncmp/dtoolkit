## What it does

"Marta solved this bug yesterday — what did she do?" Browse team sessions with tools used, model decisions, and files touched. Only content marked as shareable is visible.

Killer for onboarding — new team members can learn by watching how experienced devs work with their agents.

```bash
dreplay                         # browse recent sessions
dreplay --user marta --today    # filter by person and date
dreplay <session-id>            # replay a specific session
```
